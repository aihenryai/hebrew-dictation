- בענן המילים מועברות למנוע כרמז לזיהוי, ובמודל המקומי כהנחיה פתוחה.
- כפתור ״בדוק מיקרופון״ בהגדרות: מקליט שתי שניות ומציג איזה מיקרופון נבחר, אם נקלט קול ובאיזו עוצמה.
